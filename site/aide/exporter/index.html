Comment exporter mon carnet, et le réimporter ?

Dans MémoPatte, ouvre Paramètres › Mes données › Repère 1« Exporter mes données », puis choisis un format :

  • JSON : tout ton carnet, pour le réimporter dans MémoPatte.
  • CSV : pour l’ouvrir dans un tableur.

Tu peux enregistrer le fichier sur le téléphone, dans Documents › MémoPatte, ou le partager (Google Drive, e‑mail…).

Juste en dessous, Paramètres › Mes données › Repère 2« Exporter en PDF » crée le carnet de tous tes animaux ou d’un seul, à imprimer ou à montrer. Les exports sont gratuits et ne demandent aucun compte. Les photos ne sont pas exportées.

Pour réimporter un export JSON : Paramètres › Mes données › Repère 3« Importer un export MémoPatte ». Si des données existent déjà sur le téléphone, choisis « Fusionner » (ajoute ce qui est absent de tes données actuelles) ou « Remplacer » (remplace toutes tes données actuelles, après confirmation). MémoPatte reprogramme ensuite tes rappels.
